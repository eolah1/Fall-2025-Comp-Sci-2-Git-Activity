Does .trim just cut off extra white space
Exactly — .trim() in Java removes any leading and trailing whitespace from a string. That includes spaces, tabs (\t), and newline characters (\n, \r) at the beginning or end of the string.

Here’s a quick example:

java
String raw = "   Alice   ";
String cleaned = raw.trim();
System.out.println(cleaned); // Output: "Alice"
It does not remove spaces inside the string (like between words). So " Alice Smith ".trim() becomes "Alice Smith" — the internal space stays intact.

This is super useful when parsing input from files or user forms, where extra spaces can sneak in and cause bugs.

java
while (reader.hasNextLine()) {
    String line = reader.nextLine().trim();
    if (line.isEmpty()) {
        continue; // skip empty lines

    String[] parts = line.split(",");
    if (parts.length != 2) {
        throw new IOException("Invalid CSV format: " + line);

    String name = parts[0].trim();
    int grade;
    try {
        grade = Integer.parseInt(parts[1].trim());

    }

    students.add(new Student(name, grade));
}
This way, any line that’s just whitespace or completely blank will be ignored safely.
